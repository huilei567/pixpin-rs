PixPin-RS 便携版 v0.5.2
========================================

Rust + GPUI 写的截图 / 标注 / 贴图 / 取字工具。免安装，解压即用，删目录即卸载。
截图界面对照 PixPin 做的：放大镜取色、八向手柄、窗口吸附、图标工具栏。


【v0.5.2 新增】
  · 贴图可以再编辑了
      右键贴图 → 「编辑标注」把这张图重新送回截图界面，标注、取字、
      再贴图、保存全都照旧用。编辑期间旧贴图只是暂时藏起来：
      按 Esc 取消，原样放回去；点了贴图 / 复制 / 保存，才真正替换掉。

  · 贴图可以缩放了
      滚轮往上放大、往下缩小（以光标位置为锚点，指着哪里放哪里），
      10% ~ 400%。右键菜单里也有 缩小 / 原始大小 / 放大。
      每次都是从原图重新采样，反复缩放不会越缩越糊。

  · 贴图上直接取字
      右键贴图 → 「提取文字」，不用再框选。同一菜单里还有
      复制 / 保存 / 关闭。

  · 画笔顺了
      之前鼠标事件点稀疏，快速划一笔会看到一段段直线和硬角，
      导出后边缘还有台阶。现在轨迹先做 Chaikin 平滑，描边改成
      「到折线距离 → 覆盖率 → 每像素只混一次」，斜线边缘是柔和过渡，
      转折处也不会因为叠加而发脏。

【v0.3.3 改了什么】

  · 修了一个老 bug：主窗口缩到托盘后发起截图，贴图窗口会被藏掉且不再出现。

【v0.3.2 新增】
  · 取字结果可以自由选择了
      之前结果窗口只能整篇复制，现在：
      拖动选中一段 · 双击选词 · 三击选整行 · Shift+点击扩展选区
      Ctrl+A 全选 · Ctrl+C 复制选中（没有选中时复制全文）

      目前能改的都真实生效：
        系统      开机自动启动（写注册表 HKCU…\Run，取消勾选即删除）

        文字识别  识别后自动复制全文的开关

  新增自测开关：--text-test（直接打开取字结果窗口，验证选择交互）、
  --clicks x y n（在指定物理坐标连点 n 次，验证双击 / 三击）。


【v0.3.1 修了什么】
  · 双击启动后 Ctrl+Alt+X 不生效
      原因是这个 exe 是控制台程序，双击时会额外开一个黑色控制台窗口，
      它挡在屏幕最上层、还抢走了前台。截图其实启动了，只是覆盖层开在
      控制台窗口后面，看起来就像没反应。现在启动时会自己把这个控制台
      收掉；同时覆盖层改成强制置顶 + 主动抢前台，前台锁也拦不住。
      从命令行（cmd / bash）里启动时控制台归终端所有，不会被动。

  · 取字之后结果窗口没有置顶
      刚关掉全屏覆盖层那一刻，前台还挂在别的进程上，系统的前台锁会
      直接拒绝 SetForegroundWindow。现在结果窗口会用
      「置顶 → 挂到前台线程输入队列 → 抢焦点」三步走，下一帧再补一次，
      所以一定出现在最前面，Esc 也能直接关。

  · 双击启动后看不到主窗口
      同上，主窗口原来开在别的窗口后面，现在会主动翻到前面。

  新增 --trace 开关：把关键事件写进 pixpin-trace.log（热键注册 / 收到
  WM_HOTKEY / 覆盖层是否弹出），排查「热键没反应」时用得上。


【怎么用】
  1. 双击 PixPin-RS.exe
  2. 按 Ctrl+Alt+X，或左键点托盘图标，开始截图
  3. 拖动框选区域，松开鼠标后出现工具栏
  4. Enter 复制到剪贴板 · Ctrl+S 保存 PNG · Esc 取消

  如果按热键没反应，先看主窗口里「全局热键 Ctrl+Alt+X 已注册」那行是不是
  红的 —— 红的就是被别的软件占用了，换用托盘左键截图即可。

  没框选之前，把鼠标停在某个窗口上，那个窗口会亮起来、其余变暗，
  单击就直接选中整个窗口 —— 不用自己去对齐边角。


【截图界面】

  放大镜
    光标旁边一直跟着一个小方格，里面是 11×11 个像素放大 9 倍的样子，
    带网格和中心像素标记。右边小面板实时显示：
      屏幕坐标（物理像素）
      十六进制色值 #RRGGBB
      rgb(r, g, b)

  选区手柄
    选框四角和四条边中点各有一个白色小方块，拖它们改尺寸；
    按住选框内部拖动，可以整体平移；
    反过来拖（比如把右下角拖到左上角外面）会自动翻转，不会出错。

  尺寸徽标
    选框左上角外侧显示「x,y  宽 × 高 px」，都是屏幕物理像素。
    选框贴到屏幕顶部、或者工具栏翻到上方时，徽标会自动收进选框里面。


【工具栏】

  左半是标注工具，右半是动作，中间一道分隔线：

    [矩形] [椭圆] [画笔] [箭头] [马赛克] │ [撤销] [重做] [取字] [贴图] [保存] [复制] [关闭]

  · 选中的工具是淡蓝底 + 蓝色图标
  · 撤销 / 重做 没有历史时是灰的
  · 工具栏贴着选框右下角；下方放不下就自动翻到上方

  工具说明
    矩形 / 椭圆 / 箭头 / 画笔 —— 在选框内按住拖出来
    马赛克 —— 拖出一个矩形，那块内容会被打成色块（真打码，不是模糊）

  动作说明
    撤销 / 重做 —— 也可以 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y
    取字 —— 对选框内做本地 OCR，见下
    贴图 —— 把选框钉在屏幕上：左键拖动、滚轮缩放、双击取消钉图，
            右键菜单可再编辑 / 取字 / 复制 / 保存
    保存 —— 默认 Ctrl+S
    复制 —— 也可以 Enter / Ctrl+C
    关闭 —— 也可以 Esc

  快捷键
    Ctrl+Z          撤销
    Ctrl+Shift+Z    重做
    Ctrl+A          选中整屏
    Ctrl+C / Enter  复制
    Ctrl+S          保存
    Esc             取消


【托盘】
  左键 —— 直接截图
  右键 —— 截图 / 显示主窗口 / 退出
  关掉主窗口只是缩到托盘，热键和托盘继续可用


【贴图】
  截图后点工具栏「贴图」，选框就钉在屏幕上了（置顶，不影响别的程序）。

  左键拖动     移动位置
  滚轮         放大 / 缩小（以光标为锚点，10% ~ 400%）
  双击         取消钉图
  右键         菜单：编辑标注 / 提取文字 / 复制 / 保存 / 缩小 / 原始大小 / 放大 / 关闭

  「编辑标注」会把这张图重新送回截图界面，可以继续加箭头、打码、取字，
  弄完再贴图或复制 / 保存。按 Esc 取消编辑的话，原来那张贴图会原样回来。


【文件存哪】
  截图默认存在本目录的 screenshots\ 下。

  本目录里的 portable.txt 就是「便携模式」开关：
    · 保留它  → 截图存 exe 旁边，不碰用户目录
    · 删掉它  → 截图存到 %USERPROFILE%\Pictures\PixPinRS\


【关于「取字」功能（本地 OCR）】
  完全离线，不联网、不上传，识别全程在本机 CPU 上跑。
  模型放在 models\ 目录下：

    det.onnx           4.6 MB   DBNet 文字检测，找出画面里哪里有字
    rec.onnx          15.9 MB   PP-OCRv5 识别，把文字框里的内容读出来
    ppocrv5_dict.txt  72 KB     字典，18383 个字符

  删掉 models\ 整个目录程序照常能用，只是「取字」会提示模型缺失。

  实测速度（8 线程 CPU）：
    900×520 的选区     约 0.2 秒
    2560×1600 全屏     约 1.2 秒
    首次点「取字」要多花约 0.15 秒加载模型，之后常驻内存

  识别结果会自动去掉汉字之间多余的空格，并尽量按段落还原换行。
  识别不准的常见原因：字太小（小于 8 像素高）、艺术字体、竖排文字、
  文字压在复杂花纹背景上。加大框选范围通常能改善。


【系统要求】
  Windows 10 / 11 64 位。

  不需要安装 .NET，也不需要单独装 VC++ 运行库 —— 目录里已经带了：
    vcruntime140.dll · vcruntime140_1.dll · msvcp140.dll · msvcp140_1.dll

  d3d11.dll / dxgi.dll / dcomp.dll 都是系统自带组件。
  整个目录可以直接拷到 U 盘里跑，注意保持目录结构完整（models 别丢）。


【已知限制】
  · 只抓鼠标所在的那块屏幕，不支持跨屏框选
  · 没有长截图 / 录屏 / 翻译 / 文字标注 / 序号
  · 工具没有二级菜单，不能改线宽和样式（固定 3px 红色）
  · OCR 只支持横排文字，不支持竖排
  · 未做代码签名，首次运行 SmartScreen 可能提示「未知发布者」，
    点「更多信息」→「仍要运行」即可


【卸载】
  删掉整个目录就行，不写注册表，不在用户目录留东西。
